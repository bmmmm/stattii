# Security Policy

stattii handles capability tokens, SMTP credentials and HMAC webhook
secrets — reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead use
GitHub's private vulnerability reporting on this repository ("Report a
vulnerability" under the Security tab), or mail <hi@brtsz.de>.

You can expect an acknowledgement within a few days. Fixes ship as a
patch release; credit is given unless you prefer otherwise.

## Scope

The latest tagged release and `main`. The deployment behind
`stattii.6bm.de` is a private instance — do not test against it without
prior agreement.
